# Logo ABIS

## Instructions

Pour ajouter le logo ABIS à l'application :

1. Copiez votre fichier logo dans ce dossier
2. Renommez-le en `abis-logo.png`
3. Format recommandé : PNG avec fond transparent
4. Dimensions recommandées : 300x100px minimum ou 600x200px pour une meilleure qualité

## Emplacement Actuel

Le logo sera affiché dans :
- La barre latérale (sidebar) de toutes les pages
- La page de connexion
- L'en-tête de l'application

## Note

Si le fichier `abis-logo.png` n'est pas trouvé, le texte "ABIS" s'affichera à la place.

Pour utiliser le logo que vous avez fourni, copiez simplement l'image dans ce dossier et renommez-la `abis-logo.png`.
